# Civic Forecast fonts

Instrument Sans and Source Serif 4 are self-hosted Latin variable fonts from
Fontsource. Both are distributed under the SIL Open Font License; the original
license files are included here. These assets belong to the demo and docs apps,
so installing the React package does not download fonts.

Sources downloaded on 2026-09-23:

- https://cdn.jsdelivr.net/fontsource/fonts/instrument-sans:vf@latest/latin-wght-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/source-serif-4:vf@latest/latin-wght-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/source-serif-4:vf@latest/latin-wght-italic.woff2
